📘 Rectangular Star Pattern – Theory

The Rectangular Star Pattern is one of the most basic and important pattern programs in Python. It is used to understand the concept of nested loops.

In this pattern, stars (*) are printed in the form of a rectangle having a fixed number of rows and columns.

🔹 Concept Used
Outer Loop → Controls the number of rows.
Inner Loop → Controls the number of columns (stars printed in each row).
print("*", end=" ") prints stars in the same line.
print() moves the cursor to the next line after one row is completed.
