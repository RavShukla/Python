# 📘 Rectangular Star Pattern – Theory

The Rectangular Star Pattern is one of the most basic and important pattern programs in Python. It helps beginners understand the concept of nested loops.

In this pattern, stars (*) are printed in the shape of a rectangle using a fixed number of rows and columns.

---

## 🔹 Concepts Used

### ✅ Outer Loop
The outer loop controls the number of rows.

### ✅ Inner Loop
The inner loop controls the number of columns, meaning how many stars are printed in each row.

### ✅ print("*", end=" ")
This statement prints stars on the same line with spaces between them.

### ✅ print()
This statement moves the cursor to the next line after one row is completed.

---

## 🔄 Working Explanation

- The outer loop runs 5 times, creating 5 rows.
- For each row, the inner loop runs 6 times, printing 6 stars.

As a result, a rectangular pattern of stars is formed.

---

## 🧠 Time Complexity

O(rows × cols)

The time complexity is O(rows × cols) because each star is printed individually.

---

## 🎯 Learning Outcome

By practicing this pattern, beginners learn:

- Nested loops
- Loop execution flow
- Row and column traversal
- Basic pattern-building logic

Pattern programs are considered the foundation of logical thinking in programming.
