# 📘 Number Triangle Pattern – Theory

The Number Triangle Pattern is a basic pattern program in Python that helps in understanding nested loops and number-based pattern logic.

In this pattern, numbers are printed in increasing order starting from 1 up to the current row number, forming a triangular shape.

---

## 🔹 Concepts Used

### ✅ Outer Loop
Controls the number of rows in the pattern.

### ✅ Inner Loop
Runs from 1 to the current row number and prints values accordingly.

### ✅ Incremental Pattern Logic
Each row prints numbers from 1 up to that row index.

---

## 🔄 Working Explanation

- In the first row, only number 1 is printed.
- In the second row, numbers 1 and 2 are printed.
- This continues until the last row where numbers go from 1 to n.

Each row builds upon the previous one by adding the next number.

---

## 🧠 Time Complexity

```text
O(n²)
```

The time complexity is `O(n²)` because nested loops are used.
