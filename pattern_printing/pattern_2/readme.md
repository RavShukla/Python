# 📘 Right Triangle Star Pattern – Theory

The Right Triangle Star Pattern is a basic pattern program in Python that helps beginners understand loops and pattern-building logic.

In this pattern, the number of stars increases row by row, forming a right-angled triangle.

---

## 🔹 Concepts Used

### ✅ Loop
The loop controls the number of rows in the pattern.

### ✅ String Multiplication
The statement prints stars multiple times according to the value of the loop variable.

---

## 🔄 Working Explanation

- When the value becomes 1, one star is printed.
- When the value becomes 2, two stars are printed.
- This process continues until the last row is reached.

Each row contains one more star than the previous row.

---

## 🧠 Time Complexity

```text
O(n²)
```

The time complexity is `O(n²)` because the number of printed characters increases with each row.

By practicing this pattern, beginners learn:

- Loop execution
- Pattern-building logic
- String multiplication
- Row-wise printing

Pattern programs improve logical thinking and strengthen programming fundamentals.
