# 📘 Inverted Right Triangle Star Pattern – Theory

The Inverted Right Triangle Star Pattern is a beginner-friendly Python pattern program used to understand loops and pattern logic.

In this pattern, the number of stars decreases row by row, creating an inverted right-angled triangle.

---

## 🔹 Concepts Used

### ✅ Loop
The loop controls the number of rows and decreases the value in each iteration.

### ✅ String Multiplication
The statement prints stars multiple times according to the current loop value.

### ✅ Reverse Iteration
The loop runs in reverse order, starting from the maximum value and decreasing until 1.

---

## 🔄 Working Explanation

- The first row prints 5 stars.
- The second row prints 4 stars.
- The pattern continues decreasing by one star in each row.
- The last row prints only 1 star.

This creates an inverted triangle pattern.

---

## 🧠 Time Complexity

```text
O(n²)
```

The time complexity is `O(n²)` because stars are printed multiple times across rows.
